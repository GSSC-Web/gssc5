# Members app

- **Domain:** gssc5 members FE (Angular/Tailwind) — SoftDev/TestDev plans use members focused `ng test` / mise tasks, not LangGraph Python packaging.
- App: `gssc5-web/apps/members` (Angular + Tailwind + Eden Treaty).
- Shell uses Tailwind utilities + shared `gssc-*` theme tokens in `src/styles.css` (aligned with public); no Angular CLI welcome scaffold or custom `@media` CSS.
- Layout under `src/app/`: `pages/`, `services/`, and `modules/` (Header under `modules/header/`, Footer under `modules/footer/`). Eden Treaty client: `services/backend.ts`.
- App Root + Router (GSSC5-79 / GSSC-MLLR-1..13): `app.html` hosts Page Outlet always; Header/Footer mounts only when `MemberSession.loggedIn()` (GSSC5-100 / GSSC-MLLR-32). Root path mounts the Member Dashboard (`pages/home/`).
- Member Header (GSSC5-81 / GSSC-MLLR-14..31): chrome with logo, member-area nav, greeting/logout when logged in, login affordance when logged out — not a public Contact/Search clone. Mounted in `data-slot="header"` only while the App Root chrome gate is open. Explicit Header logout navigates to `/login` with no return-path query (GSSC-MLLR-93).
- Member Footer (GSSC5-82 / GSSC-MLLR-40..66): `modules/footer/` reads society fields via `services/kv-store/` + `services/society-contact/` (same KVS keys as public). Contact overlay open is stubbed in `services/contact-overlay/`. Mounted only while logged in.
- Auth Wave 2 append / PIR-32 (GSSC5-86–88): `pages/login/` (GSSC-MLLR-72..91); `services/member-session.ts` cookie challenge + `login()` + logout (GSSC-MLLR-67..71); `services/auth-guards.ts` `requireAuthGuard` / `redirectIfAuthenticatedGuard` with `returnUrl` query (GSSC-MLLR-92..95). Members FE still does not mint tokens.
- Member Generic Sections display (GSSC5-83 / GSSC-MLLR-96..124): read-only `modules/section/` Container + `modules/section-from-cuid/` loader + `services/section-display-window/` (mirrors public); `services/files-api.ts` for featured images. Not the Generic Editor (GSSC5-84).
- Member Dashboard (GSSC5-89 / GSSC-MLLR-231..239; HLR GSSC-MHLR-26..28): `pages/home/` at `/` under `requireAuthGuard`; loads `dashboard`-tagged sections via Section From CUID; user moderators (admin ⊃ userMod) get Generic Editor + form fields per section with PATCH save. SoftDev/TestDev: members FE.
- Account forms (GSSC5-90/91 / GSSC-MLLR-125..158): shared `pages/account/` for `/account` (self) and `/accounts/:cuid` (user-moderator management); three sections (member info, account info, password); `services/account-api.ts` for GET/POST user + password change. SoftDev/TestDev: members FE, not LangGraph Python.
- Contact-row / Form Primitives (GSSC5-85 / GSSC-MLLR-159..179; HLR GSSC-MHLR-25 + GSSC-MHLR-61): reusable `modules/contact-row/`, `modules/form-text-field/`, `modules/form-select-field/`, `modules/form-zip-ext-row/`, `modules/form-password-criteria/` for directory and editor/account chrome. Does not own the Generic Editor module (GSSC5-84). SoftDev/TestDev: members FE.
- Generic Editor Module (GSSC5-84 / GSSC-MLLR-180..201; HLR GSSC-MHLR-24): `modules/editor/` shell + `services/editor-session/` exclusive-edit registry. Hosts project GSSC5-85 form fields into the Field Area; Save/Cancel, permission gate, contention unavailable. Not display-only sections (GSSC5-83). SoftDev/TestDev: members FE.
- Members Directory + Search (GSSC5-92 / GSSC-MLLR-202..214 exact end; band **202–230** reserved; HLR GSSC-MHLR-55..59): `pages/directory/` at `/directory` behind `requireAuthGuard`; `services/directory-api.ts` lists/filters via Eden Treaty GET `/users`; search uses GSSC5-85 Form Text Field; results use Contact Row. Administrators see Registered Members heading on the same page (backend projection). SoftDev/TestDev: members FE.
- Page/Section Content Editor (GSSC5-93 / **GSSC-MLLR-261..286**; HLR GSSC-MHLR-38..42): `pages/page-section-editor/` at `/page-sections` (auth-gated); page-tag selector + section list + Generic Editor host + Section preview; `services/sections-api.ts` for GET/PATCH `/sections` via Eden Treaty. Exclusive edit resource id `section:{cuid}`. SoftDev/TestDev: members FE.
- Announcements Editor (GSSC5-94 / PIR-16 / **claims GSSC-MLLR-291..307**; HLR GSSC-MHLR-43..45): `pages/announcements-editor/` at `/announcements` + `services/announcements-api.ts`. Hosts Generic Editor (84) + form primitives (85); create/modify/publish via GSSC5-68 `/announcements` (+ `/templates` for create). Publication Target maps members→`isPublic false`, public|both→`isPublic true`. SoftDev/TestDev: members FE.
- Newsletters Editor (GSSC5-96 / GSSC-MLLR-351..373; HLR GSSC-MHLR-49..51 → **GSSC-PIR-54**): `pages/newsletters/` at `/newsletters` behind `requireAuthGuard`; Generic Editor host for create/modify; `services/newsletters-api.ts` Eden Treaty `GET|POST /newsletters` + `GET|PATCH /newsletter/{cuid}`; permission `isAdmin || isNewsletterEditor` (`MemberSession` hydrates `isNewsletterEditor`). SoftDev/TestDev: members FE, not LangGraph Python.
- Events Editor (GSSC5-95 / **claims GSSC-MLLR-321..346**; HLR GSSC-MHLR-46..48): `pages/events/` at `/events` (auth guard) composing `gssc-editor` + form fields; `services/events-api.ts` → backend `/events` (GSSC5-69). Create / publish (`isPublic`) / modify; user-moderator permission gate. SoftDev/TestDev: members FE.
- Publications/Tools editors (GSSC5-97 / **GSSC-MLLR-381..414**; HLR GSSC-MHLR-52..54): auth-guarded `pages/publications/` (`/publications`) and `pages/research-tools/` (`/research-tools`); compose Generic Editor + form-text fields; `services/publications-api.ts` + `services/research-tools-api.ts` for catalog CRUD; `MemberSession.isPublicationEditor` / `isToolEditor` (admin ⊃ editor) gate create/save/delete. SoftDev/TestDev: members FE, not LangGraph Python.
- StrictDoc UID blocks in `docs/members/Members_LLR.sdoc`: GSSC5-80 claims no MLLRs; GSSC5-79 owns **GSSC-MLLR-1..13**; GSSC5-81 owns **GSSC-MLLR-14..31**; GSSC5-100 owns **GSSC-MLLR-32** (+ CHANGE_DRIVER on MLLR-1); GSSC5-82 owns **GSSC-MLLR-40..66**; GSSC5-87 owns **67..71**; GSSC5-86 owns **72..91**; GSSC5-88 owns **92..95**; GSSC5-83 owns **96..124**; GSSC5-90/91 own **125..158**; GSSC5-85 owns **159..179**; GSSC5-84 owns **180..201**; GSSC5-92 owns **202..214** (reserved band through **230**); GSSC5-93 owns **261..286**; GSSC5-89 owns **231..239**; GSSC5-94 owns **291..307**; GSSC5-95 owns **321..346**; GSSC5-96 owns **351..373** (band 351–380); GSSC5-97 owns **381..414**; gap **33..39** remain free for non-contiguous claimants.
- Backend client uses credentialed `fetch` so the HttpOnly Login Token cookie is sent (`gssc_login_token` issued by backend).
- Auth consumption only — members FE does not mint or persist raw login tokens; session comes from cookie + backend challenge.
- Build/test via mise under the members app (`mise` tasks in `gssc5-web` / app `mise.toml`).
- **Testing harness (GSSC5-80, mirrors public GSSC5-39):** `src/test-harness.ts` (`setupMembersComponent`, DOM helpers), `src/test-providers.ts` (wired via `angular.json` `providersFile`), `**/*.test.ts` beside sources. Run with `mise run //members:test`. No testing-framework MLLRs; do not unit-test the harness. SoftDev/TestDev must use members `ng test` / mise — not LangGraph Python packaging.
