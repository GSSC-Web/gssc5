# Members app

- **Domain:** gssc5 members FE (Angular/Tailwind) — SoftDev/TestDev plans use members focused `ng test` / mise tasks, not LangGraph Python packaging.
- App: `gssc5-web/apps/members` (Angular + Tailwind + Eden Treaty).
- Shell uses Tailwind utilities + shared `gssc-*` theme tokens in `src/styles.css` (aligned with public); no Angular CLI welcome scaffold or custom `@media` CSS.
- Layout under `src/app/`: `pages/`, `services/`, and `modules/` (Header under `modules/header/`, Footer under `modules/footer/`). Eden Treaty client: `services/backend.ts`.
- App Root + Router (GSSC5-79 / GSSC-MLLR-1..13): `app.html` hosts Page Outlet always; Header/Footer mounts only when `MemberSession.loggedIn()` (GSSC5-100 / GSSC-MLLR-32). Root path mounts the Member Dashboard (`pages/home/`).
- Member Header (GSSC5-81 / GSSC-MLLR-14..31; nav chrome GSSC5-107 / GSSC-MHLR-81..86 + GSSC-MLLR-441..461): three-tier sticky chrome (wide/mid/narrow) with procedural Navigation Menu from `GET /site-trees/members` via `services/site-tree/` (≤2 submenu levels; not Angular-route-driven); logo + org name (wide full / mid acronym / narrow omit); Site Search control + overlay widget (GSSC5-109); greeting/logout when logged in, login when logged out; **no Donate**, no Public Contact clone. Mounted in `data-slot="header"` only while the App Root chrome gate is open (GSSC5-100). Explicit Header logout navigates to `/login` with no return-path query (GSSC-MLLR-93).
- Member Footer (GSSC5-82 / GSSC-MLLR-40..66; sitemap link GSSC5-108 / GSSC-MLLR-501..503): `modules/footer/` reads society fields via `services/kv-store/` + `services/society-contact/` (same KVS keys as public). Contact overlay open is stubbed in `services/contact-overlay/`. Footer Sitemap Link opens `/sitemap`. Mounted only while logged in.
- Members Sitemap Page (GSSC5-108 / GSSC-MLLR-504..510; HLR GSSC-MHLR-79..80): `pages/sitemap/` at `/sitemap` behind `requireAuthGuard`; fetches `GET /site-trees/members` and renders a nested destination listing; UID band **501–510** (reserve 501–520); GSSC5-107 nav **441–461**, GSSC5-109 site search **462–483** (band 462–500). SoftDev/TestDev: members FE.
- Members Site Search (GSSC5-109 / **GSSC-MLLR-462..483**; HLR **GSSC-MHLR-87..88**; band **462–500**): Header overlay (query + quick results via Eden Treaty `GET /search?frontend=members&limit=`; result navigate; submit → `/search`) and auth-gated `pages/search/` with kind filter — **not** Directory Search (GSSC5-92). Service: `services/site-search/`. SoftDev/TestDev: members FE. Distinct from Public GSSC5-47 (Public SDoc only).
- Members Site Tree Editor (GSSC5-116 / **GSSC-MLLR-521..540**; HLR **GSSC-MHLR-89..92**; band **521–560**): admin CRUD/reorder UI at `pages/site-tree-editor/` (`/site-trees`, `requireAuthGuard`) over Done GSSC5-40 `GET|POST /site-trees/{frontend}` + `PATCH|DELETE /site-trees/{frontend}/nodes/{nodeId}` for Public and Members trees; `services/site-trees-api.ts`. GSSC5-113 Prismabox polish is related only, not a gate. SoftDev/TestDev: members FE.
- Auth Wave 2 append / PIR-32 (GSSC5-86–88): `pages/login/` (GSSC-MLLR-72..91); `services/member-session.ts` cookie challenge + `login()` + logout (GSSC-MLLR-67..71); `services/auth-guards.ts` `requireAuthGuard` / `redirectIfAuthenticatedGuard` with `returnUrl` query (GSSC-MLLR-92..95). Members FE still does not mint tokens.
- Member Generic Sections display (GSSC5-83 / GSSC-MLLR-96..124): read-only `modules/section/` Container + `modules/section-from-cuid/` loader + `services/section-display-window/` (mirrors public); `services/files-api.ts` for featured images. Not the Generic Editor (GSSC5-84).
- Member Dashboard (GSSC5-89 / GSSC-MLLR-231..239; HLR GSSC-MHLR-26..28): `pages/home/` at `/` under `requireAuthGuard`; loads `dashboard`-tagged sections via Section From CUID; user moderators (admin ⊃ userMod) get Generic Editor + form fields per section with PATCH save. SoftDev/TestDev: members FE.
- Account forms (GSSC5-90/91 / GSSC-MLLR-125..158; refinement GSSC5-101 / GSSC-MLLR-415..428; mailing=home GSSC5-103 / GSSC-MHLR-78 + GSSC-MLLR-429..437): shared `pages/account/` for `/account` (self) and `/accounts/:cuid` (user-moderator management); three collapsible sections (expanded by default) each as a form so Enter submits that section; submit-time required/format validation with red invalid fields; account photo bordered preview + floating-label Choose Photo (hidden native file input) uploading via `/account-photos` for the loaded user cuid; password rejects unmet criteria and current/previous reuse; mailing-equals-home checkbox between home and mailing (init checked iff values match; when checked, home edits copy to mailing and mailing fields disable/gray); `services/account-api.ts` for GET/POST user + password change + photo upload. SoftDev/TestDev: members FE (+ backend account-photos), not LangGraph Python.
- Contact-row / Form Primitives (GSSC5-85 / GSSC-MLLR-159..179; HLR GSSC-MHLR-25 + GSSC-MHLR-61): reusable `modules/contact-row/`, `modules/form-text-field/`, `modules/form-select-field/`, `modules/form-zip-ext-row/`, `modules/form-password-criteria/` for directory and editor/account chrome. Does not own the Generic Editor module (GSSC5-84). SoftDev/TestDev: members FE.
- Generic Editor Module (GSSC5-84 / GSSC-MLLR-180..201; HLR GSSC-MHLR-24): `modules/editor/` shell + `services/editor-session/` exclusive-edit registry. Hosts project GSSC5-85 form fields into the Field Area; Save/Cancel, permission gate, contention unavailable. Not display-only sections (GSSC5-83). SoftDev/TestDev: members FE.
- Members Directory + Search (GSSC5-92 / GSSC-MLLR-202..214; refinement GSSC5-102 / GSSC-MLLR-215..230 exact end **230**; HLR GSSC-MHLR-55..59): `pages/directory/` at `/directory` behind `requireAuthGuard`; `services/directory-api.ts` lists/filters via Eden Treaty GET `/users` (Name / Email / Phone / Address→home; backend `name` + `address` filters); filter bar has a distinct surface from results; results are contact cards (square photo or silhouette, name/info left of actions; Edit for userMod/admin → managed Account Page; soft-delete/undelete for admin). Administrators see Registered Members heading and soft-deleted state (backend projection). SoftDev/TestDev: members FE.
- Page/Section Content Editor (GSSC5-93 / **GSSC-MLLR-261..286**; HLR GSSC-MHLR-38..42): `pages/page-section-editor/` at `/page-sections` (auth-gated); page-tag selector + section list + Generic Editor host + Section preview; `services/sections-api.ts` for GET/PATCH `/sections` via Eden Treaty. Exclusive edit resource id `section:{cuid}`. SoftDev/TestDev: members FE.
- Announcements Editor (GSSC5-94 / PIR-16 / **claims GSSC-MLLR-291..307**; HLR GSSC-MHLR-43..45): `pages/announcements-editor/` at `/announcements` + `services/announcements-api.ts`. Hosts Generic Editor (84) + form primitives (85); create/modify/publish via GSSC5-68 `/announcements` (+ `/templates` for create). Publication Target maps members→`isPublic false`, public|both→`isPublic true`. SoftDev/TestDev: members FE.
- Newsletters Editor (GSSC5-96 / GSSC-MLLR-351..373; HLR GSSC-MHLR-49..51 → **GSSC-PIR-54**): `pages/newsletters/` at `/newsletters` behind `requireAuthGuard`; Generic Editor host for create/modify; `services/newsletters-api.ts` Eden Treaty `GET|POST /newsletters` + `GET|PATCH /newsletter/{cuid}`; permission `isAdmin || isNewsletterEditor` (`MemberSession` hydrates `isNewsletterEditor`). SoftDev/TestDev: members FE, not LangGraph Python.
- Events Editor (GSSC5-95 / **claims GSSC-MLLR-321..346**; HLR GSSC-MHLR-46..48): `pages/events/` at `/events` (auth guard) composing `gssc-editor` + form fields; `services/events-api.ts` → backend `/events` (GSSC5-69). Create / publish (`isPublic`) / modify; user-moderator permission gate. SoftDev/TestDev: members FE.
- Publications/Tools editors (GSSC5-97 / **GSSC-MLLR-381..414**; HLR GSSC-MHLR-52..54): auth-guarded `pages/publications/` (`/publications`) and `pages/research-tools/` (`/research-tools`); compose Generic Editor + form-text fields; `services/publications-api.ts` + `services/research-tools-api.ts` for catalog CRUD; `MemberSession.isPublicationEditor` / `isToolEditor` (admin ⊃ editor) gate create/save/delete. SoftDev/TestDev: members FE, not LangGraph Python.
- StrictDoc UID blocks in `docs/members/Members_LLR.sdoc`: GSSC5-80 claims no MLLRs; GSSC5-79 owns **GSSC-MLLR-1..13**; GSSC5-81 owns **GSSC-MLLR-14..31**; GSSC5-100 owns **GSSC-MLLR-32** (+ CHANGE_DRIVER on MLLR-1); GSSC5-82 owns **GSSC-MLLR-40..66**; GSSC5-87 owns **67..71**; GSSC5-86 owns **72..91**; GSSC5-88 owns **92..95**; GSSC5-83 owns **96..124**; GSSC5-90/91 own **125..158**; GSSC5-85 owns **159..179**; GSSC5-84 owns **180..201**; GSSC5-92 owns **202..214**; GSSC5-102 owns **215..230** (exact end 230; also CHANGE_DRIVER on MLLR-205..208); GSSC5-93 owns **261..286**; GSSC5-89 owns **231..239**; GSSC5-94 owns **291..307**; GSSC5-95 owns **321..346**; GSSC5-96 owns **351..373** (band 351–380); GSSC5-97 owns **381..414**; gap **33..39** remain free for non-contiguous claimants; GSSC5-101 owns **415..428** (and CHANGE_DRIVER on MLLR-146); GSSC5-103 owns **429..437** (exact end 437; HLR MHLR-78); GSSC5-102 also owns **438..440**; GSSC5-107 owns **441..461** (exact end 461; also CHANGE_DRIVER on MLLR-14/15/18/20/21; HLR MHLR-81..86); GSSC5-109 owns **462..483** (band 462–500; HLR MHLR-87..88); GSSC5-108 sitemap owns **501..510** (band 501–520; HLR MHLR-79..80); GSSC5-116 site-tree editor owns **521..540** (band 521–560; HLR MHLR-89..92).
- Backend client uses credentialed `fetch` so the HttpOnly Login Token cookie is sent (`gssc_login_token` issued by backend).
- Auth consumption only — members FE does not mint or persist raw login tokens; session comes from cookie + backend challenge.
- Build/test via mise under the members app (`mise` tasks in `gssc5-web` / app `mise.toml`).
- **Testing harness (GSSC5-80, mirrors public GSSC5-39):** `src/test-harness.ts` (`setupMembersComponent`, DOM helpers), `src/test-providers.ts` (wired via `angular.json` `providersFile`), `**/*.test.ts` beside sources. Run with `mise run //members:test`. No testing-framework MLLRs; do not unit-test the harness. SoftDev/TestDev must use members `ng test` / mise — not LangGraph Python packaging.
