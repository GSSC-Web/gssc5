# Members app

- **Domain:** gssc5 members FE (Angular/Tailwind) — SoftDev/TestDev plans use members focused `ng test` / mise tasks, not LangGraph Python packaging.
- App: `gssc5-web/apps/members` (Angular + Tailwind + Eden Treaty).
- Color mode (GSSC5-125 / MHLR-105/106 / MLLR-650..655; footer pin GSSC5-136 / GSSC-180): same `ThemeMode` + `html.dark` org-token remap as Public; Footer under `html.dark` pins `--color-gssc-black`/`--color-gssc-white` (and `--gssc-black`/`--gssc-white`) so Tailwind utilities keep dark chrome — `--gssc-*` alone does not override resolved `--color-gssc-*`; Header Theme Toggle; logo plate on dark chrome (Header/Footer/Login marks). Persisted preference applies even when Header is omitted for logged-out visitors. No `gssc-cream` token.
- Shell uses Tailwind utilities + shared `gssc-*` theme tokens in `src/styles.css` (aligned with public); no Angular CLI welcome scaffold or custom `@media` CSS.
- **Nerd Font icons (GSSC-177):** Do **not** `@import` full Nerd Fonts `webfont.css`. Keep Symbols-only `@font-face` (pinned nerd-fonts Symbols on jsDelivr) plus a hand-maintained `.nf` / `.nf-*:before { content: … }` glyph subset in `src/styles.css`. SoftDev rule: whenever introducing or using an `nf-*` class in templates, add the matching `:before` glyph (and base `.nf` if needed) in **both** Public and Members `src/styles.css` subsets, using the nerd-fonts cheat sheet for the pinned Symbols version.
- Layout under `src/app/`: `pages/`, `services/`, and `modules/` (Header under `modules/header/`, Footer under `modules/footer/`). Eden Treaty client: `services/backend.ts`.
- App Root + Router (GSSC5-79 / GSSC-MLLR-1..13): `app.html` hosts Page Outlet always; Header/Footer mounts only when `MemberSession.loggedIn()` (GSSC5-100 / GSSC-MLLR-32). Root path mounts the Member Dashboard (`pages/home/`).
