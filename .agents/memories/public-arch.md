# Public app

- **Domain:** gssc5 public FE (Angular/Tailwind) — SoftDev/TestDev plans use focused `ng test` / `mise run //public:test`, not LangGraph Python/`src/gssc_langgraph` packaging.
- App: `gssc5-web/apps/public` (Angular + Tailwind + Eden Treaty).
- Layout under `src/app/`: `modules/`, `pages/`, `services/`; multi-file classes get a folder. Bootstrap stays in `src/app/`.
- Header (GSSC5-45): sticky host in `app.html`; procedural Public Navigation Menu from `GET /site-trees/public` via `services/site-tree/` (home from root + root children, ≤2 submenu levels); three-tier chrome (wide nav bar under identity / mid hamburger / narrow search–logo–hamburger); sticky overlay menus; no Donate; Login/Contact kept (narrow utilities live in the overlay).
- Modules include `header`, `footer`, `announcements-bar`, `error` (Error Container: bottom-right Page Outlet panel; light/dark-red chrome matching Prompt field fail; admin collapsibles; Report/Dismiss chrome; Esc-when-focused + focus restore), `section` (Section Container places Contents: white chrome, 1.5× header, black body; optional featured image when Contents have `imageFile` + `imagePosition` `left`|`right` — side-by-side at `sm+`, between header and body below `sm`, omitted for `none`/missing file/position; max 3/5 width and 2/5 parent; resolves via credentialed `GET /files/{cuid}` — GSSC5-74; equal Resource Buttons in a left-aligned horizontal strip; looping prev/next carousel only when the strip overflows Section width, with strip movement via CSS `translateX` slide on Prev/Next — GSSC-PLLR-93 / GSSC5-66), `carousel` (Carousel Container places Contents items as slides: header/body/resources string→links + optional featured image via same resolve token as Section; auto-advance + Prev/Next when multiple items; optional `focusedItemId`; omit when empty — GSSC5-26 / PLLR-263–283; home page composition remains GSSC5-14), `section-from-cuid` (takes a backend section cuid, fetches via Eden Treaty `GET /sections/{cuid}`, maps resources string→name/href and optional image fields, and renders through the Section Container; omits when optional start/end display window excludes today — GSSC5-67 / PLLR-258), `calendar` (Public month calendar GSSC5-30: prev/next month chrome, Sunday–Saturday day grid with event chips from Eden Treaty `GET /events` via `CALENDAR_EVENTS_LIST_GET`; inclusive span from page_data start/end or catalog date; multi-day chips on each day / week-row segments with title repeat; Event Detail Overlay matching Prompt Overlay Escape+X dismiss chrome with Section-like title/body/featured image/resources; featured image via `SECTION_FEATURED_IMAGE_RESOLVE`), `prompt-overlay` (Prompt Overlay shell + child field modules: `text-field`, `select-field`, `options-field`, `button-field`, `file-field`, `options-list-field`, `prompt-form`).
- Section display windows: `services/section-display-window/` (`isSectionVisibleOn` / `filterSectionsVisibleOn`) applied by Section From CUID and by membership / leadership / newsletter tag list factories (GSSC5-67 / PLLR-259).
- Home page (`pages/home/`, GSSC5-14): Announcements Carousel via `gssc-carousel` + `GET /announcements` (display-window filtered; `?focusAnnouncement=` deep link); special-event sections from `GET /events` within ±1 month of occurrence as Section Contents; other dynamic sections via `GET /sections?tag=home` + Section From CUID (purpose / library / cookbook when authored — no Purpose-only UI). Featured Photos deferred (BHLR-170 has no endpoint). Page assemblies that load live sections use `gssc-section-from-cuid` (GSSC5-50).
- Sitemap page (`pages/sitemap/`, GSSC5-41): `GET /site-trees/public` via Eden Treaty; nested listing of the full Public site tree (`gssc-sitemap-tree` recursive entries); route `/sitemap`; Footer Sitemap Link in `modules/footer/`. Not nav chrome (GSSC5-45).
- Research Tools page (`pages/research-tools/`, GSSC5-18): Society Resources and Tools List requests `GET /research-tools` via Eden Treaty and renders a refined Research Resources hyperlink grid (title → reference link) as normal page content — not nested under Section / Section From CUID / tagged generic sections. Cemetery Project pages stay out of this page task.
- Publications page (`pages/publications/`, GSSC5-19): Society Publications List requests `GET /publications` via Eden Treaty and renders a refined Publications hyperlink grid (title → reference link; optional description below title) as normal page content — not nested under Section / Section From CUID. Cemetery Project and War Veterans stay out of this catalog.
- Leadership page (`pages/leadership/`, GSSC5-16): optional intro via `GET /sections?tag=leadership` + Section From CUID; Officers (large cards, ≤3 cols) and Directors at Large (small cards, ≤5 cols, centered leftovers) with fixed Position slots; Vacant → red theme; Committee Chairs dynamic from leadership list entries that are not Officers/Directors (alpha by Position, no Vacant); preferred contact → mailto/tel; photo or SVG placeholder.
- Membership page (`pages/membership/`, GSSC5-15): lists public sections by tag `membership-info` via Eden Treaty `GET /sections?tag=…`, then places each cuid through `gssc-section-from-cuid` in backend section order (omit when none). Membership application (PHLR-75) is deferred to GSSC5-70.
- Calendar page (`pages/calendar/`, GSSC5-17): optional miscellaneous notices via `GET /sections?tag=calendar` + Section From CUID (omit when empty) above embedded `gssc-calendar` (GSSC5-30 month view); token `CALENDAR_PAGE_SECTION_LIST_BY_TAG`. Deliberately empty calendar section on other pages stays out of scope.
- Generic modules: `contact-card-large`, `contact-card-small` (photo / name / title / italic contact; Vacant uses light/dark-red tokens).
- Newsletters page (`pages/newsletters/`, GSSC5-20): catalog from `GET /newsletters` (volume/number/month/year/filePath/keywords); optional intro via `GET /sections?tag=newsletter` + Section From CUID (omit when empty); Volume/Number ↔ Month/Year selection-mode toggle (default Volume/Number); query deep-links `?cuid=` (preferred), `?volume=&number=`, or `?year=&month=` (invalid → newest); preview/download resolve `filePath` via credentialed `GET /files/{cuid}` (GSSC5-71 on this branch — ACL + soft-delete → omit chrome on 403/404); blob object URLs for iframe/download; tokens `NEWSLETTER_CATALOG_GET` / `NEWSLETTER_SECTION_LIST_BY_TAG` / `NEWSLETTER_FILE_RESOLVE`.
- Services include `backend` (credentialed `fetch`), `member-session`, `public-error` (current Application/HTTP Error Contents; clear on dismiss/report), `urgent-announcements`, `prompt-overlay` (queued prompt forms), `contact-overlay` (Header/Footer open hook; enqueues the Contact Overlay form on the prompt queue), `leadership` (public leadership list + intro sections by tag), contact/KV helpers.
- Prompt Overlay: service queue of form configs; overlay chrome (gray/25% backdrop, fullscreen below `sm`, ≤¾ viewport at `sm+`); dismiss via top-right control or Escape only (no backdrop dismiss).
- Contact Overlay (GSSC5-31): Header/Footer Contact open the service; form title Contact with Name, Email, Contact reason, Message, and Submit via Prompt Overlay field modules; Contact reason defaults to General Inquiry (title-case options including Website Issue); Name/Email autofill from MemberSession when signed in; submit completes the draft with no send/mail API. Phone/email/postal stay on Footer; contact page section stays empty by design.
- MemberSession also holds optional `emailAddress` (local UI signal, same pattern as `displayName`) for Contact Overlay autofill; Login Token remains HttpOnly-cookie only. Refresh: challenge returns `{ status, cuid? }` → authenticated `GET /users/{cuid}` hydrates `displayName` + `isAdministrator` (GSSC5-58).
- Theme tokens on `:root` in `src/styles.css`: `--gssc-light-green` `#C5CAB6`, `--gssc-dark-green` `#61684D`, `--gssc-cream` `#FFFFCC`, `--gssc-light-brown` `#D8BA98`, `--gssc-dark-brown` `#92745D`, `--gssc-gray` `#D4D4D4`, white/black, plus `--gssc-light-red` / `--gssc-dark-red` (Prompt field fail family for Error Container). Outermost shell background white; default typeface sans-serif.
- Public shell (`app.html` / host class) and Section Container presentation use Tailwind utilities and `gssc-*` theme tokens instead of layout rules in `app.css` / `section.css` (GSSC5-63). `app.css` keeps only the `:host { display: block }` hook; `section.css` removed. Announcements-bar already on utilities (GSSC5-53).
- Login Token is HttpOnly cookie `gssc_login_token`; public FE consumes session via credentialed requests — it does not store the raw token.
- Tests: `src/test-harness.ts`; `*.test.ts` beside sources; `mise run //public:test`.
